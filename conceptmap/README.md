# 國中生協作概念圖評分回饋系統（GitHub Pages＋Firebase 版）

📍 第一版 BY 桃子腳
👥 製作團隊：張文良(作者_桃子腳國中)、鄭鴻哲(協作_桃子腳國中)、霍建豪(協作_桃子腳國中)、翁正鴻(協作_南港高中)

純前端網頁，放在 GitHub Pages；帳號用 Firebase Authentication，資料與圖檔存在 Firestore（`cm_` 開頭的集合）。

## 上線前必做（Firebase 主控台，專案 cp-tools-2c4d2）

1. **Authentication → 開始使用 → Sign-in method → 啟用「電子郵件/密碼」**。
2. **Firestore Database → 規則**：貼上本 repo 的 `firestore.rules` 全文並發布（或執行 `firebase deploy --only firestore:rules`）。
3. 打開網站，**立刻用帳號名稱 `admin` 註冊** —— 這個帳號就是最高管理者。請用強密碼；在你註冊之前，任何人先註冊 `admin` 都會取得最高權限。
4. 其他老師先自行註冊，再由 admin 在「帳號管理」把身分改成教師或管理者。

## 使用方式

- 學生：註冊 → 上傳概念圖（文本＋每人個人圖＋協作圖）→ 等老師評分 → 看自己的評分表與回饋。
- 教師：開啟小組 → 「AI 判讀並評分」（需在設定頁填自己的 Anthropic API 金鑰，金鑰只存在該裝置瀏覽器）或「判讀匯入／修正」→ 「資料下載」匯出 Excel／CSV／圖檔 ZIP。
- 網址加上 `?local=1` 是本機試用模式：不連 Firebase，資料只存在該瀏覽器，可用來熟悉操作。

## 設計重點

- `scoring.js`：Novak 計分（關係 1、階層 5、例子 1、交叉連結 10）、貢獻值五維度與三公式、回饋文字。純函式，不含任何特定文本內容。
- 判讀結果以「文本雜湊＋原始檔 SHA-256＋頁碼」為鍵保存，同一張圖重傳會取回同一份判讀，分數與細節完全一致。
- 分數只有教師以上的帳號能寫入（安全規則限制），學生端無法竄改。
- 上傳的 PDF／圖片會在瀏覽器轉成一張 JPEG（長邊最多 2200px、約 0.9MB 以內）再存檔。

## 已知限制

- 概念圖只接受 PDF 與瀏覽器可讀的圖片（JPG／PNG／WEBP／GIF／BMP）；Word、PPT、HEIC 請先另存成 PDF 或 JPG。
- 忘記密碼無法由管理者重設：請剔除舊帳號後用新帳號名稱重新註冊。
- 被剔除的帳號無法再使用系統，但其 Firebase 登入紀錄需到主控台 Authentication 才能完全刪除。
- Firestore 免費額度約 1GB，約可存 1,500～2,500 張概念圖。
- AI 判讀功能尚未以真實金鑰驗證過。
